## 1.4 Операции над векторами и матрицами в NumPy 

**numpy.repeat(a, repeats, axis=None)**
повторяет каждый элемент массива заданное количество раз.

|Параметр|Описание|
|-|--------|
|a|Входной массив или массивоподобный объект
|repeats|Число повторов: int (для всех элементов) или массив int (индивидуально для каждого)
|axis|Ось, вдоль которой повторять. По умолчанию (None) массив сплющивается

Новый массив ndarray с повторёнными элементами.


**np.newaxis** - добавление измерений в NumPy
```np.newaxis``` — это псевдоним для None, который используется при индексации массивов, чтобы добавить новое измерение (ось) в массив. Это мощный и лаконичный способ менять форму массива без копирования данных.

|Задача|Пример использования|
|-|-|
|Преобразовать 1D → 2D (вектор-строка/столбец)|arr[:, np.newaxis]|
|Подготовить данные для broadcasting|a[:, np.newaxis] + b|
|Добавить канал в изображение (H×W → H×W×1)|img[:, :, np.newaxis]|
|Совместить оси для матричных операций|x[np.newaxis, :] @ y[:, np.newaxis]|


```Python
import numpy as np

# 🔹 1D → 2D: вектор-столбец
a = np.array([1, 2, 3])           # shape: (3,)
col = a[:, np.newaxis]            # shape: (3, 1)
# array([[1],
#        [2],
#        [3]])
```

**broadcasting** - https://numpy.org/doc/stable/user/basics.broadcasting.html

Broadcasting (транслирование) — это механизм NumPy, позволяющий выполнять арифметические операции над массивами разной формы без явного копирования данных. Меньший массив «растягивается» виртуально, чтобы соответствовать большему.

```Python
A = np.array([[0, 0, 0],
              [10, 10, 10],
              [20, 20, 20]])   # shape: (3, 3)
b = np.array([1, 2, 3])         # shape: (3,)

A + b
# array([[ 1,  2,  3],
#        [11, 12, 13],
#        [21, 22, 23]])
# b добавляется к каждой строке A

```

**np.matmul()** - матричное умножение в NumPy

numpy.matmul(a, b, out=None) — выполняет матричное произведение двух массивов. Это основная функция для линейной алгебры в NumPy, соответствующая оператору @.

|Параметр|Описание
|-|--------|
|a, b|Входные массивы (скаляры не поддерживаются!)
|out|(опционально) массив для сохранения результата


**np.asmatrix** — преобразование в матрицу (устаревшая функция)
numpy.asmatrix(data, dtype=None) — преобразует входные данные в объект np.matrix (двумерная матрица), а не в обычный ndarray.

|Параметр|Описание|
|-|--------|
|data|Массив, список, кортеж или любой массивоподобный объект
|dtype|(опционально) желаемый тип данных результата
